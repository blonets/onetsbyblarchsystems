# دليل التركيب للفنيين — منصة إدارة راوترات MikroTik

> الدليل ده للفني اللي بينزل الموقع. مفيش حاجة معقدة: سطر واحد بيتلزق في التيرمنال
> والراوتر بيظهر في اللوحة لوحده. اقرا الخطوات بالترتيب ومتستعجلش.

## قبل ما تروح الموقع

1. يكون معاك **التوكن** — كود من اللوحة (Panel → Sites → اسم الموقع → Onboard router).
   التوكن ده **بيستخدم مرة واحدة بس** وصلاحيته **15 دقيقة**. لو خلصت المدة، اطلب واحد جديد.
2. يكون معاك لابتوب أو موبايل عليه **WinBox** أو SSH، وكابل للراوتر.
3. الراوتر لازم يكون **شغال وفيه إنترنت** (أي إنترنت — حتى لو ورا NAT، مش محتاج IP عام).

## الخطوة 1: خد سطر التركيب

من اللوحة هتلاقي سطر واحد شكله كده (القيم هتختلف عندك):

```
/tool fetch mode=https address=panel.example.com src-path=/api/v1/onboard/AbC123XyZ/onboard.rsc dst-path=onboard.rsc; /import onboard.rsc
```

- ده سطر واحد: بيحمّل ملف التركيب من اللوحة، وبعدين بينفّذه.
- التوكن (`AbC123XyZ` في المثال) هو الإثبات إن الراوتر ده تبع موقعك.

## الخطوة 2: الصق السطر في تيرمنال الراوتر

1. افتح WinBox وادخل على الراوتر (اليوزر `admin`).
2. افتح **New Terminal**.
3. **الصق السطر كامل** ودوس Enter.
4. استنى 10–20 ثانية لحد ما يخلص من غير أخطاء حمرا.

> ⚠️ متقفّلش التيرمنال ولا تفصل الراوتر وهو بينفّذ السكريبت.

## السكريبت عمل إيه في الراوتر؟ (عشان تبقى فاهم، مش عشان تعمل حاجة)

| الحاجة | التفصيل |
|---|---|
| **SSTP client** | الراوتر بقى بيتصل هو بنفسه بسيرفر الشركة المركزي (TCP 443 — بيعدي من أي فايروول زي الـ HTTPS). الاتصال طالع من الراوتر، فمش محتاج IP عام ولا فتح بورتات. |
| **يوزر مقيّد `panel-api`** | يوزر جديد بصلاحيات قليلة على قد الإدارة (قراية وكتابة للإعدادات، من غير ما يشوف باسوردات ولا يعمل sniff ولا reboot). ده اللي اللوحة بتتكلم بيه مع الراوتر. |
| **هوية الراوتر (UUID)** | رقم تعريفي فريد اتسجّل على الراوتر واتربط باسمه في اللوحة — هو اللي بيأكد إن الراوتر ده هو هو مش واحد تاني. |
| **Watchdog** | مهمة مجدولة كل دقيقتين بتتأكد إن الاتصال شغال؛ لو وقع بتحاول ترجّعه لوحدها وبتسجّل في الـ log. |
| **Callback** | الراوتر بلّغ اللوحة إنه خلص، فالتوكن اتحرق (مبقاش صالح للاستخدام تاني). |

**السكريبت مبيغيّرش** إعدادات الهوت سبوت ولا الفايروول ولا الإنترنت بتاع الموقع. هو بيضيف
اتصال الإدارة بس.

## الخطوة 3: اتأكد إن الراوتر ظهر في اللوحة

1. ارجع للوحة → **Routers** — دوّر على اسم الموقع.
2. لازم تلاقي الراوتر بحالة **🟢 online** وجنبه الـ tunnel IP (بيبدأ بـ `10.200.`).
3. دوس على الراوتر → لازم تشوف بياناته (موديل الجهاز، نسخة RouterOS، الـ CPU).

لو ظهر online → **خلاص، التركيب خلص.** اقفل التيرمنال وامسح ملف `onboard.rsc` لو لسه موجود
(مش ضروري، بس نضافة).

## لو حصلت مشكلة — جدول الأعطال

| العَرَض | السبب الغالب | الحل |
|---|---|---|
| `fetch failed` أو `connection timeout` في التيرمنال | مفيش إنترنت على الراوتر، أو التوكن خلصت مدته | اتأكد الراوتر طالع إنترنت (`/ping 8.8.8.8`)، واطلب توكن جديد من اللوحة |
| `import: script error` أو سطر أحمر | نسخة RouterOS قديمة أو السطر اتلصق ناقص | انسخ السطر كامل تاني من الأول للآخر؛ لو لسه فيه خطأ كلم الدعم وابعتله صورة الخطأ |
| الراوتر مش ظاهر في اللوحة بعد 5 دقايق | الـ SSTP مش متصل | في التيرمنال نفّذ: `/interface sstp-client print` — لازم تلاقي حرف **R** (Running) جنب الاتصال. لو مفيش R، نفّذ: `/interface sstp-client enable [find name=sstp-hub]` واستنى دقيقة |
| الـ SSTP متصل (R) بس اللوحة شايفاه offline | الـ API user فيه مشكلة أو الفايروول قافل | نفّذ: `/user print where name=panel-api` — لازم اليوزر يكون موجود ومش disabled. وبعدين: `/log print where topics~"panel-watchdog"` وشوف آخر سطر بيقول إيه |
| كل حاجة شغالة بس عايز تتأكد | — | `/log print where topics~"panel-watchdog"` — لازم تشوف سطور بتقول إن الفحص نجح كل دقيقتين |

## أوامر مفيدة (انسخ والصق عند الحاجة)

```
# حالة اتصال الإدارة
/interface sstp-client print

# إعادة الاتصال يدويًا
/interface sstp-client disable [find name=sstp-hub]
/interface sstp-client enable [find name=sstp-hub]

# سجل الـ watchdog
/log print where topics~"panel-watchdog"

# التأكد من يوزر اللوحة
/user print where name=panel-api

# الـ IP بتاع النفق (لازم يبدأ بـ 10.200.)
/ip address print where interface~"sstp"
```

## ممنوعات

- 🚫 **متمسحش** يوزر `panel-api` ولا مهمة الـ watchdog — اللوحة هتفقد الراوتر.
- 🚫 **متغيّرش** إعدادات الـ SSTP client بإيدك (السيرفر/اليوزر/الباسورد) — أي تغيير
  اعمله من اللوحة وهي هتظبط الراوتر لوحدها.
- 🚫 **متبعتش** التوكن ولا أي باسورد على واتساب أو في جروب — التوكن لمرة واحدة،
  بس العادة دي خطر.
